# PL-300 Recap

A one-page interactive closing recap for the PL-300 Microsoft Power BI Data Analyst course. It covers the four skills: prepare, model, visualize and analyze, and manage and secure.

Each section has an objective, four key ideas to open, and one quick-check question. Use the left and right arrow keys to move between sections while presenting.

Plain HTML, CSS and JavaScript, with no build step. Open `index.html` or use the GitHub Pages link.
